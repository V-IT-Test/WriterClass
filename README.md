# WriterClass
### Описание задачи

Целью данного проекта является автоматическая классификация русскоязычных текстов по авторам. Необходимо построить модель, способную по входному тексту определить, кто из шести авторов (Генри, Симак, Булгаков, Брэдбери, Фрай, Стругацкие) является его автором.

### Цели

Получить классификатор с высокой точностью.

Испробовать подход с свёрточной нейронной сетью (CNN) для классификации текстов.

## Обоснование выбора подхода

### Обработка данных

Использована SpaCy (модуль ru_core_news_sm) для лемматизации и фильтрации пунктуации, пробелов и стоп-слов.

Разбиение на предложения с использованием sentencizer.

Отбор только текстов, достигающих минимальной длины.

### Архитектура модели

Embedding → Conv1D → GlobalMaxPooling1D → Dropout → Dense → Dropout → Dense (softmax)

Embedding: преобразует токены в векторы размерности 256

Conv1D: 128 фильтров с ядром размером 5

GlobalMaxPooling1D: сжатие сверточных результатов

Dropout: 0.5 для борьбы с переобучением

Dense: 128 нейронов с ReLU и L2-регуляризацией

Output: softmax-слой со стольком нейронов, сколько классов

### Гиперпараметры

MAX_SAMPLES_PER_CLASS = 2000

MAX_SEQUENCE_LENGTH = 190

VOCAB_SIZE = 40000

EMBEDDING_DIM = 256

DROPOUT_RATE = 0.5

L2_REG = 0.01
